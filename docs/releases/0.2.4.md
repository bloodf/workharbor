WorkHarbor 0.2.4 adds quick access to the tools you use most, directly from the macOS menu bar.

## What's new

- **Quick options:** secondary click or Control-click the menu-bar icon to open the agenda, settings, refresh, or quit.
- **Familiar primary click:** the agenda opens and closes with the primary click, using the existing calendar view.
- **Accessible actions:** the status button exposes Open agenda and Quick options to assistive technologies, alongside native keyboard activation.
- **Predictable menu behavior:** dismissing the menu runs no command. Refresh is unavailable until Calendar access is already available and is checked again when selected.
- **Multilingual interface:** English, Brazilian Portuguese, and Spanish labels are included.

## Download and installation

Download `WorkHarbor-0.2.4-macos-arm64.zip` for an Apple Silicon Mac running macOS 14 or later, together with its `.sha256` file. This is an arm64 build, not a universal or Intel build.

Verify the download with:

```sh
shasum -a 256 -c WorkHarbor-0.2.4-macos-arm64.zip.sha256
```

Extract the ZIP, quit an earlier WorkHarbor instance, and move WorkHarbor.app to Applications if desired. Open Settings to configure the calendars already available in Apple Calendar.

## Signing

This preview is **ad-hoc signed and is not notarized by Apple**. macOS may prevent it from opening. Keep macOS security protections enabled. The complete source is available under the MIT license for inspection and local builds.

## Validation and current limits

The release was checked with 102 automated unit tests and a synthetic AppKit exercise covering 133 checks and 17 native menu presentations. These checks cover event routing, cancellation, repeated opening and closing, and action selection. They do not constitute a physical trackpad test, a live VoiceOver session, or certification of every calendar provider.

Calendar synchronization runs while WorkHarbor is open and the Mac is awake. Missing events are preserved; background synchronization does not delete events. Calendar providers remain responsible for remote delivery.
